# DSH Hunt public roadmap

This roadmap describes user-facing work areas. It does not promise delivery dates.

## Current focus

- Publish static plugin structure evidence tied to fixed source commits.
- Explain evidence coverage and limits on package detail pages.
- Review community submissions and corrections manually, then run them through release checks.
- Keep source links, report identity, and correction scope visible.

## Areas under consideration

- Improve the clarity and discoverability of evidence pages and methodology guidance.
- Add narrow regression cases when a reproducible analysis-rule issue is confirmed.
- Make reviewed correction history easier to understand from the affected report.

These items are subject to evidence quality, available maintenance time, and release review.

## Outside the first release

- Running or installing third-party plugins, including runtime compatibility testing.
- Treating static evidence as a security audit or endorsement.
- Paid commercial features or account-based workflows.
- Automated acceptance or automatic changes to published reports from an Issue.
